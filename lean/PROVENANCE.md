# Provenance of lean/ and data/lean/

`lean/` is the source tree `src/` of the frozen module-form port of the Lean development (snapshot 2026-10-08 06:54:17 UTC;
its manifest `MANIFEST_FULL.md5`, with md5 7c5a67484a5335c4d4c4b5b69ac3ddb1, lists 315,565 files), without the files of Rudich and Rousseau, which
are a dependency (see the README). `data/lean/` is the frozen data `snap/data/` of the same tree. The only change is that the
absolute paths of the data files inside the sources are replaced by paths relative to the repository root, so the build runs
from the root. The final file is `lean/R22B/FinalTop.lean`.

The final file also imports modules generated by the computation: the glue modules that combine the batches and the batch
modules themselves (`lean/tools/ext_modules.txt`). They are not in this repository. They are produced by running the
computation again (`data/RECIPE.txt`, `scripts/native/`), and `data/run/` lists all batches with their hashes.
